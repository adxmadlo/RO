Comment fonctionne cette version

Cette application traite les problèmes de maximisation et de minimisation. Pour un modèle standard avec contraintes ≤ et seconds membres positifs, la base initiale est donnée par les variables d'écart. Si le problème contient des contraintes ≥ ou =, l'application ajoute des variables artificielles et lance automatiquement une phase I.

Variables d'écart Variables de surplus Variables artificielles
Forme standard : Ax + e − s + a = b   avec   x, e, s, a ≥ 0
Phase I : recherche d'une base réalisable  ·  Phase II : optimisation de la fonction objectif
① Standardisation : normalisation éventuelle des seconds membres et transformation des contraintes
② Itérations : variable entrante, variable sortante, pivot et ratio minimal
③ Diagnostic : optimum, infaisabilité ou non-bornitude
